# 투자실무

거래 규칙, 비용과 세금, 상품 구조, 위험 관리를 공식 자료로 따라가는 실전 학습 사이트이다. 경제 개념을 다루는 [경제학습](https://jiseop-byeon.github.io/economics-studies/)의 형제 사이트이다.

이 사이트는 매매를 권하지 않으며 종목이나 시점을 고르지 않는다. 세금과 계약은 계산의 구조까지만 다루고, 개인의 결론은 세무사, 법무사, 금융회사에 확인하도록 안내한다.

## 구조

- 목차(`js/toc.js`): 공통 실무에서 시작해 주식, 채권, 선물과 옵션, 원자재와 금, 부동산, 가상자산, 위험 관리, 자료 읽기, 사고 사례, 미국 시장으로 내려간다. 장마다 `ready`(읽을 수 있음)와 `planned`(쓸 예정)를 표시한다.
- 장 본문(`js/chapters.js`): 경제학습의 글처럼 쉬운 말로 쓰고, 핵심 용어는 `<h3>` 구획으로 세운다. 구획마다 뜻, 작동 방식, 예시, 헷갈리기 쉬운 점을 두고, 장 끝에 "읽다 생기는 질문"을 둔다. 문체는 한다체이다.
- 실전 용어(`js/glossary.js`): `<h3>` 용어의 한자와 영어. 제목 옆에 자동으로 붙는다.
- 규칙 데이터(`js/rules.js`): 거래 시간, 가격 장치, 결제일, 세율처럼 바뀌는 숫자를 한곳에 둔다. 본문은 `<span data-rule="ID"></span>`로 불러오므로, 제도가 바뀌면 이 파일 한 줄만 고친다. 항목마다 시행일, 확인한 날, 확인 수준(공식 자료 / 보도·안내 / 원문 대조 전), 출처를 적는다. `#/rules`는 같은 데이터로 한국과 미국을 나란히 보여 준다.
- 경제학습 연결: 본문에서 `href="econ:t019"`처럼 쓰면 경제학습의 용어 카드로 이어진다.

## 표기

쉬운 말을 먼저 쓰고, 공식 용어가 있으면 처음 나올 때 `쉬운 말(용어 漢字 · English, 약어)`로 단다.

## 로컬에서 보기

```bash
python3 -m http.server 8766
```

빌드 단계는 없다. 읽음 기록은 이 브라우저의 `localStorage`(`practice-v1`)에만 남고, 밝기 설정은 경제학습과 함께 쓴다.
